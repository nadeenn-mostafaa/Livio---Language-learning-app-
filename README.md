Livio — Language Learning App | UI/UX Case Study
UI/UX design case study for a fitness and nutrition app.
 Project Overview :

Livio is a language-learning app concept designed to help users learn languages naturally through series, movies, songs, and real-life experiences. The goal is to make language learning more engaging, practical, and immersive.

Project Goal :

To design a user-friendly learning experience that helps users discover useful phrases, understand content through subtitles, practice real-life situations, and improve their language skills.

 My Role:

Team leader -UI/UX Designer @ Group Project

 Tools:

Figma

Google Forms

 Research & UX Process Completed :

User Survey: Gathered feedback about language-learning habits, preferences, and challenges.

User Interviews: Explored users' experiences, needs, motivations, and pain points.

Competitor Analysis: Evaluated existing language-learning platforms to identify opportunities for improvement.

SWOT Analysis: Analyzed strengths, weaknesses, opportunities, and threats relevant to the concept.

Empathy Map: Organized users' thoughts, feelings, behaviors, and challenges.

Affinity Map: Grouped research findings into meaningful patterns and themes.

User Persona: Created a research-informed representation of the target user.

General Insights: Summarized key findings to guide design decisions.

Currently in Progress : 

Card Sorting: Organizing content and features according to users' mental models.

Sitemap: Defining the app's information architecture and navigation structure.

User Journey Map: Mapping the user's experience, actions, emotions, and pain points throughout the app.

-Key Concept Features :

Learn languages through series, movies, and songs.

Explore phrases and save useful expressions.

View dual subtitles to support comprehension.

Receive AI-powered learning feedback.

Practice real-life scenarios.

Engage in conversations with native speakers.
